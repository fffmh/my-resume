## 数据分析师 · 范文要点

### 工作经历写法
- 突出数据规模、分析场景、业务影响（带来的增长/成本下降/决策改变）。
- 示例：「搭建用户增长看板体系，覆盖 200+ 指标，支撑运营周会决策；通过漏斗分析定位流失节点，注册转化率提升 18%。」
- 示例：「负责 A/B 实验评估，累计上线 300+ 实验，为业务贡献 GMV 增长约 5%。」

### 项目/分析报告写法
- 按「分析背景 / 数据与方法 / 关键结论 / 落地动作与收益」结构。
- 关键词：SQL、Python、Pandas、Tableau、PowerBI、A/B 测试、漏斗分析、指标体系、数据可视化。

### 技能写法
- 工具 + 业务 + 统计三类分开列。
- 加分项：埋点设计、数据治理、指标体系、因果推断、自动化报表。

### 自我评价
- 示例：「4 年数据分析经验，擅长从业务问题出发设计指标体系；能用数据讲故事、推动决策落地，注重结果可量化。」

### 整体结构
基本信息 → 求职意向 → 技能 → 工作经历 → 项目/分析案例 → 教育经历 → 证书 → 自我评价。
