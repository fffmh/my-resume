## 前端开发工程师 · 范文要点

### 工作经历写法
- 用「负责 / 主导 / 搭建 / 重构 / 优化」开头，先讲职责范围再讲结果。
- 每个要点尽量带量化：耗时、性能百分比、覆盖人数、接入业务数。
- 示例：「主导组件库建设，基于 Vue3 + TypeScript 沉淀 40+ 通用组件，业务接入率 72%，页面开发效率提升 30%。」
- 示例：「推动微前端改造，应用启动耗时降低 38%，首屏从 3.2s 优化至 1.1s。」

### 项目经历写法
- 按「项目背景 / 我的角色 / 技术方案 / 结果」四段式。
- 技术栈单独一行列出，方便关键词命中。
- 示例：「实时数据中台（前端负责人）：基于 Vue2 + WebSocket + ECharts 建设商家经营实时看板，日均 10 万级查询，卡顿率下降 60%。」

### 技能写法
- 按岗位相关度排序，不要堆砌；熟练度标注「精通 / 熟练 / 了解」。
- 前端岗位常见关键词：Vue3、React、TypeScript、微前端、性能优化、工程化、Vite、Webpack、Node.js、可视化。

### 自我评价
- 2-4 句：经验年限 + 核心能力 + 工作方式 + 结果导向。
- 示例：「5 年前端开发经验，专注工程化与性能优化；习惯用数据衡量结果，追求可持续的高质量交付。」

### 整体结构
基本信息 → 求职意向 → 技能 → 工作经历 → 项目经历 → 教育经历 → 证书 → 自我评价。
