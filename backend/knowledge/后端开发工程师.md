## 后端开发工程师 · 范文要点

### 工作经历写法
- 突出系统规模、QPS/TPS、可用性、稳定性与性能指标。
- 示例：「负责订单中心重构，支撑日均 5000 万订单、峰值 QPS 3 万，可用性 99.99%，接口 P99 延迟从 800ms 降至 120ms。」
- 示例：「主导微服务拆分与治理，服务从 20 个扩展到 120 个，发布效率提升 60%，线上事故率下降 45%。」

### 项目经历写法
- 写清业务复杂度与个人贡献边界：「我负责 XX 模块 / 设计 XX 方案 / 解决 XX 难题」。
- 技术关键词：Java、Spring Boot、Go、MySQL、Redis、Kafka、RabbitMQ、微服务、分布式、高并发、Docker、K8s。

### 技能写法
- 按「语言 / 框架 / 中间件 / 基础设施」分组，标注熟练度。
- 加分项：稳定性建设、容量规划、性能调优、代码评审、技术文档。

### 自我评价
- 示例：「6 年后端开发经验，擅长高并发与分布式系统设计；注重可观测性与稳定性，习惯用数据定位与验证问题。」

### 整体结构
基本信息 → 求职意向 → 技能 → 工作经历 → 项目经历 → 教育经历 → 证书 → 自我评价。
